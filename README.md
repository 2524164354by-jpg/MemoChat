# MemoChat（微记）

一款"和自己聊天"的安卓日记 App。不用工整排版，想到什么就发什么，像给朋友发微信一样简单。

## 功能

- **多条目**：按"日记 / 吐槽 / 工作"等话题分开记录，互不干扰
- **聊天式界面**：发消息即用，气泡风格，上手零成本
- **补记**：选任意日期补发，自动归档到当天并标注"补发"
- **心情与天气**：随手记录当天状态，形成情绪曲线
- **星标**：重要消息一键收藏，集中查看
- **广场**：
  - 我的数据：写作统计、连续天数、心情走势
  - 回忆抽卡：随机翻一条以前写的
  - 时光胶囊：写给未来的自己
  - 写点什么：全屏安静记录
- **深色模式**：自动跟随系统，浅色 / 深色随时切换
- **自定义背景**：可更换聊天壁纸
- **回收站**：删除内容 30 天内可恢复
- **备份导出**：文字导出与完整备份

## 技术

- 语言：Kotlin
- UI：传统 XML 布局 + ViewBinding
- 本地存储：Room
- 最低版本：Android 8.0+

## 下载 / 安装

当前为本地工程，可直接用 Android Studio 打开编译安装到手机。
